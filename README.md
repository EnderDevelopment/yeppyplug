# Yeppyplug: A Customizable Minecraft Plugin for Enhanced Item Drops

Yeppyplug is a Minecraft plugin designed to enhance the item drop experience with customizable holograms. It leverages the DecentHolograms API to create and manage holograms that appear when players drop items. This plugin is perfect for server administrators who want to add a touch of customization and interactivity to their Minecraft servers.

## Install

1. Download the Yeppyplug plugin JAR file from the [GitHub repository](https://github.com/EnderDevelopment/Yeppyplug).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Drop an item in the game world.
2. A hologram will appear above the dropped item, displaying the text "Dropped Item".
